# Agentic Interconnection Risk Screener

An agentic AI capstone project that screens renewable-energy and storage projects in the CAISO (California ISO)
interconnection queue for **development and interconnection realization risk**: how likely a project is to withdraw,
stay stuck in the queue, or reach commercial operation, and on what timeline.

The planned agent combines three tools:

1. **SQL** over public queue and grid data (CAISO, Berkeley Lab).
2. **Machine-learning risk models** trained on the CAISO queue history.
3. **Retrieval (RAG)** over CAISO transmission plans and the Berkeley Lab *Queued Up* report.

The scope is interconnection and development risk, not investment underwriting.

### Key findings so far

- **Classifier:** a calibrated random forest trained on projects queued in 2016 or earlier reached test PR-AUC 0.455 and
  ROC-AUC 0.753. Its predicted probability levels drift upward on later cohorts, so it is better used for ranking than
  as a precise forecast.
- **Survival EDA:** withdrawal is fast (39% of projects withdraw within one year) and operation is slow (3% by year 5,
  12% by year 10). Treating withdrawal as ordinary censoring overstates the probability of operation by year 8
  roughly fourfold (34% instead of 9%).
- Withdrawals arrive in bursts tied to each cluster's process milestones. Successful operations are scarce in recent
  clusters (2 in Clusters 13 to 15), and the protective association of storage with lower withdrawal fades in
  recent years. Section 13 of the survival EDA notebook gives the full verdict and the recommended modeling approach.

## Getting the data

The data folders are excluded from git. Download the public files below and save them **under the exact local filenames
shown**, because the notebooks read these paths (relative to `Notebooks/`).

### `Data_ML_SQL/`

| Local filename | Source |
|---|---|
| `CASIO_Cluster_14_and_Prior_Interconnection_Requests.xlsx` | CAISO public generator interconnection queue report (Cluster 14 and prior: active, completed, and withdrawn sheets). Available from the [CAISO generator interconnection page](https://www.caiso.com/generation-transmission/generation/generator-interconnection), via the [public queue report library](https://www.caiso.com/library/public-queue-report), or exported from the Reporting tab of CAISO RIMS. |
| `CASIO_Cluster_15_Interconnection_Requests.xlsx` | CAISO [Cluster 15 queue report](https://www.caiso.com/library/interconnection-queue-reports) |
| `Berkeley_LabQueue_Data_2025.xlsx` | Berkeley Lab [*Queued Up* data file](https://emp.lbl.gov/queues) (interconnection data through the end of 2025) |
| `CASIO_production_and_curtailments_2020.xlsx` … `CASIO_production_and_curtailments_2025.xlsx` | CAISO [production and curtailments data](https://www.caiso.com/library/production-curtailments-data), one file per year |

### `Data_RAG/`

| Local filename | Source |
|---|---|
| `Berkeley_Lab_Queued_Up_2026.pdf` | Berkeley Lab [*Queued Up: 2026 Edition*](https://emp.lbl.gov/queues) report |
| `board-approved-2025-2026-transmission-plan.pdf` | [CAISO 2025-2026 Transmission Plan](https://www.caiso.com/documents/board-approved-2025-2026-transmission-plan.pdf) |
| `board-approved-2025-2026-transmission-plan-appendix-h-projects.pdf` | [Appendix H: Project Need and Description](https://www.caiso.com/documents/board-approved-2025-2026-transmission-plan-appendix-h-projects.pdf) |

**Note on snapshots:** the queue reports change as CAISO updates them. The analyses here use the Cluster 14-and-prior
report with `Report Run Date: 09/24/2026`. A newer download will have different counts, so the notebooks' reconciliation
checks (for example 252 operational, 1,764 withdrawn, and 262 active projects) will need updating.

## Setup

Requires Python 3.12.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

`lifelines` requires `pandas < 3`, so the environment uses pandas 2.3.

## Running the notebooks

Open the notebooks in Jupyter (or Cursor/VS Code) with the `.venv` kernel and run them top to bottom. To execute one
from the command line:

```bash
cd Notebooks
jupyter nbconvert --to notebook --execute --inplace \
  --ExecutePreprocessor.timeout=1500 EDA_Survival_Competing_Risks_CAISO_Cluster_14_and_15.ipynb
```

If your global Jupyter config references extensions that are not installed, prefix the command with
`JUPYTER_CONFIG_DIR=/tmp/jupcfg` to run with a clean config.

Run the classifier notebook (`ML_Model_...ipynb`) before anything that needs `Models/`, because it creates
`caiso_c14_classifier.joblib`, `model_metadata.json`, and `validation_holdout_ids.csv`.

## Data and usage notes

- All data come from public sources (CAISO and Lawrence Berkeley National Laboratory). Check each source's terms
  before redistributing the files.
- Model outputs are screening signals for interconnection risk, not investment advice or forecasts of individual
  project outcomes.
