📊 KEY STATISTICS AT A GLANCE:

Dataset:        38,202 interconnection requests (2000-2025)
Target:         Queue Status (4 classes - see imbalance below)
Features:       30 variables (categorical + numerical + temporal)

Class Distribution:
  - Operational (Success):   13,156 records (34.4%) ← Target class 1 (for binary)
  - Active (Pending):         9,427 records (24.7%)
  - Withdrawn (Failure):     14,524 records (38.0%) ← Target class 0 (for binary)
  - Suspended:                1,095 records (2.9%)  ← Underrepresented

Top Predictive Features:
  1. type_1 (Resource Type)     - ⭐⭐⭐⭐⭐ Strongest
  2. region (ISO/RTO)            - ⭐⭐⭐⭐ Strong
  3. service (ERIS vs NRIS)      - ⭐⭐⭐ Moderate
  4. total_mw (Project Capacity) - ⭐⭐ Weak
  5. q_year (Submission Year)    - ⭐⭐ Temporal

Data Quality:
  ✓ Missing data <5% in critical fields
  ⚠ High missingness: developer (69%), project_name (73%)
  ✓ No data entry errors in core features
  ⚠ Class imbalance: 14:1 ratio (operational:suspended)

📞 QUICK REFERENCE: COMMON QUESTIONS

Q: What's the target variable?
A: Queue Status (q_status) - 4 classes
   For ML: Use Withdrawn (binary) or Operational (binary)
   See: EDA_SUMMARY.md section 2

Q: What features should I use?
A: type_1, region, service, total_mw, q_year, is_hybrid
   See: FEATURE_REFERENCE.md section 1, Table 1

Q: How should I handle missing data?
A: Strategy depends on feature - see FEATURE_REFERENCE.md section 6
   Summary:
   - Numerical: Impute with median by type_1
   - Categorical: Create "missing" flag
   - Sparse features: Drop (developer, project_name)

Q: What encoding should I use?
A: Depends on cardinality:
   - type_1: One-hot (7 categories)
   - region: Target encoding (15+ categories)
   - service: One-hot (4 categories)
   See: FEATURE_REFERENCE.md section 3

Q: How do I handle class imbalance?
A: Use multiple strategies:
   - SMOTE oversampling
   - Class weights
   - Stratified cross-validation
   See: EDA_SUMMARY.md section 7.2

Q: What model should I use?
A: XGBoost or LightGBM
   Why: Best for tabular data, feature importance, handles missing values
   See: EDA_SUMMARY.md section 8

Q: How do I evaluate my model?
A: Stratified by region and resource type
   Primary metric: Recall (don't miss rejections)
   See: EDA_SUMMARY.md section 8.2
